🐛 常见问题

Q: 无法访问 localhost:5173？

A: 如果您在远程服务器上，可能需要：

  • 使用 VSCode 的端口转发功能
  • 使用 SSH 隧道: ssh -L 5173:localhost:5173 your-server
  • 或者配置 nginx 反向代理

Q: 页面显示连接失败？

A: 检查后端服务是否运行：

curl http://localhost:3000/health

Q: 如何重启服务？

A: 在终端执行：

cd /home/user/LS/demo/backend npm run dev & cd /home/user/LS/demo/frontend npm run dev &
